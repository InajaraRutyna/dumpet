# Dumpet på Måne Syv

A story game for practising Danish on a phone.

- **The game:** https://inajararutyna.github.io/dumpet/ (your saved progress is kept on your device).
- **The new version, being built:** https://inajararutyna.github.io/dumpet/ny/ (it saves separately, so the two never mix).

Everything is drawn and composed in code: no images, no recordings. Fonts in the new version: Space Grotesk and Fraunces, under the SIL Open Font License.
